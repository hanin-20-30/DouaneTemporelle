## Description

Application Android (Java) qui simule un poste de douane pour voyageurs du temps :

1. **MainActivity** : formulaire d'enregistrement (nom, année de naissance, année de destination, motif).
2. **VerificationActivity** : passeport temporel, boutons Approuver / Refuser.
3. **ResultActivity** : verdict (fond vert ou rouge) et retour au formulaire.
